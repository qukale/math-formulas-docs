# Math formulas

Учебный проект: функции для вычисления **площади** и **периметра**
круга, квадрата, прямоугольника и треугольника.

## Установка

1. Склонируйте репозиторий:

```bash
   git clone https://github.com/qukale/math-formulas-docs.git
   cd math-formulas-docs
```

2. Требуется Python 3, сторонние библиотеки не нужны.

## Пример использования

```python
import circle
import rectangle

print(circle.area(2))           # 12.566370614359172
print(rectangle.perimeter(3, 4))  # 14
```
