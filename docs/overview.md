# Общее описание решения

Проект содержит набор функций для вычисления **площади** и **периметра**
плоских геометрических фигур: круга, квадрата, прямоугольника и треугольника.
Каждая фигура реализована в отдельном модуле, функции в модулях называются
одинаково (`area` и `perimeter`), поэтому их нужно вызывать через имя модуля.

## Структура проекта

| Файл           | Назначение                          |
|----------------|-------------------------------------|
| `circle.py`    | площадь и длина окружности круга    |
| `square.py`    | площадь и периметр квадрата         |
| `rectangle.py` | площадь и периметр прямоугольника   |
| `triangle.py`  | площадь и периметр треугольника     |
| `docs/`        | документация проекта                |

## Используемые формулы

| Фигура        | Площадь              | Периметр             |
|---------------|----------------------|----------------------|
| Круг          | $S = \pi R^2$        | $P = 2 \pi R$        |
| Квадрат       | $S = a^2$            | $P = 4a$             |
| Прямоугольник | $S = ab$             | $P = 2(a + b)$       |
| Треугольник   | $S = \frac{ah}{2}$   | $P = a + b + c$      |

## Пример использования

```python
import circle
import triangle

print(circle.area(2))              # 12.566370614359172
print(triangle.perimeter(3, 4, 5)) # 12
```
