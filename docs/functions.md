## circle.py

### `circle.area(r)`

Возвращает площадь круга по радиусу.

| Параметр | Тип     | Описание           |
|----------|---------|--------------------|
| `r`      | `float` | радиус круга, r ≥ 0 |

**Возвращает:** `float` — площадь круга, $S = \pi R^2$.

```python
import circle

print(circle.area(2))  # 12.566370614359172
```

### `circle.perimeter(r)`

Возвращает длину окружности по радиусу.

| Параметр | Тип     | Описание           |
|----------|---------|--------------------|
| `r`      | `float` | радиус круга, r ≥ 0 |

**Возвращает:** `float` — длина окружности, $P = 2 \pi R$.

```python
import circle

print(circle.perimeter(1))  # 6.283185307179586
```

## square.py

### `square.area(a)`

Возвращает площадь квадрата.

| Параметр | Тип     | Описание                 |
|----------|---------|--------------------------|
| `a`      | `float` | длина стороны, a ≥ 0     |

**Возвращает:** `float` — площадь, $S = a^2$.

```python
import square

print(square.area(3))  # 9
```

### `square.perimeter(a)`

Возвращает периметр квадрата.

| Параметр | Тип     | Описание                 |
|----------|---------|--------------------------|
| `a`      | `float` | длина стороны, a ≥ 0     |

**Возвращает:** `float` — периметр, $P = 4a$.

```python
import square

print(square.perimeter(3))  # 12
```

## rectangle.py

### `rectangle.area(a, b)`

Возвращает площадь прямоугольника.

| Параметр | Тип     | Описание                     |
|----------|---------|------------------------------|
| `a`      | `float` | длина первой стороны, a ≥ 0  |
| `b`      | `float` | длина второй стороны, b ≥ 0  |

**Возвращает:** `float` — площадь, $S = ab$.

```python
import rectangle

print(rectangle.area(3, 4))  # 12
```

### `rectangle.perimeter(a, b)`

Возвращает периметр прямоугольника.

| Параметр | Тип     | Описание                     |
|----------|---------|------------------------------|
| `a`      | `float` | длина первой стороны, a ≥ 0  |
| `b`      | `float` | длина второй стороны, b ≥ 0  |

**Возвращает:** `float` — периметр, $P = 2(a + b)$.

```python
import rectangle

print(rectangle.perimeter(3, 4))  # 14
```

## triangle.py

### `triangle.area(a, h)`

Возвращает площадь треугольника по основанию и высоте.

| Параметр | Тип     | Описание                              |
|----------|---------|---------------------------------------|
| `a`      | `float` | длина основания, a ≥ 0                |
| `h`      | `float` | высота, проведённая к основанию, h ≥ 0 |

**Возвращает:** `float` — площадь, $S = \frac{ah}{2}$.

```python
import triangle

print(triangle.area(6, 4))  # 12.0
```

### `triangle.perimeter(a, b, c)`

Возвращает периметр треугольника по трём сторонам.

| Параметр | Тип     | Описание                     |
|----------|---------|------------------------------|
| `a`      | `float` | длина первой стороны, a ≥ 0  |
| `b`      | `float` | длина второй стороны, b ≥ 0  |
| `c`      | `float` | длина третьей стороны, c ≥ 0 |

**Возвращает:** `float` — периметр, $P = a + b + c$.

```python
import triangle

print(triangle.perimeter(3, 4, 5))  # 12
```
